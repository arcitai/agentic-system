# Brand assets

Revision: 0.1.34 · Updated: 2026-11-06

`banner.html` is the editable source for `agentic-system-banner.png` (1536 × 384).
Serve this directory locally, wait for `document.fonts.ready`, and capture the
`main` element at its native size. The README scales the image down for display.

The unchanged mark, Geist fonts and blue `#4265a0` hover accent come from
[Arc’ It AI’s website at 46e5566](https://github.com/arcitai/arcitai-website/tree/46e5566e5f4d1f89fc36df43cd5a35c79ff504f5).
The source's [license notice](https://github.com/arcitai/arcitai-website/blob/46e5566e5f4d1f89fc36df43cd5a35c79ff504f5/README.md#license)
excludes brand names and logos from its software license. The Arc’ It AI name
and logo, including their use in this banner, are not licensed for reuse under
Agentic Systems' MIT license. The Geist fonts retain their separate license in
`fonts/LICENSE.txt`. These presentation assets are not included in the staged
Agentic Systems skills.

`agentic-system-icon.svg` is the editable source of the transparent blue agentic system glyph for the public Notion guide; `agentic-system-icon.png` is its native browser export. It matches the owner's rounded gradient Notion icon style. It is a presentation asset under the same branding exception, not part of a staged skill.
