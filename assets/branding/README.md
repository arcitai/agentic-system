# Brand assets

Revision: 0.2.2 · Updated: 2026-11-20

`agentic-system-icon.svg` is the editable mark: three connected cream modules
on a rounded blue square. It is adopted from the Agentic System card under
Current work on [Gustav Online](https://gustavonline.com/), originally at
`/assets/project-marks/agentic-systems.svg`. The PNG is a 1024 × 1024 export
of that vector. Use the same mark for the Notion guide and repository presentation.
These files are presentation assets and are not included in staged skills.

`banner.html` is the editable source for `agentic-system-banner.png` (1536 × 384).
Serve this directory locally, wait for `document.fonts.ready`, and capture the
`main` element at its native size. The banner uses the connected-module mark.

The retained `arcitai-mark.svg` is historical Arc’ It AI artwork from
[its website at 46e5566](https://github.com/arcitai/arcitai-website/tree/46e5566e5f4d1f89fc36df43cd5a35c79ff504f5).
That source’s [license notice](https://github.com/arcitai/arcitai-website/blob/46e5566e5f4d1f89fc36df43cd5a35c79ff504f5/README.md#license)
excludes Arc’ It AI brand names and logos from its software license. Those retained
assets keep their separate terms. The current connected-module icon is separate
from that mark. Geist fonts retain their license in `fonts/LICENSE.txt`.
