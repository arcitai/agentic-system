# Work modules

Revision: 0.1.34 · Updated: 2026-11-06

The `adlc/` path is retained for compatibility with portable distributions.
Choose the methods the task needs; these files do not require six agents or a
fixed sequence. Software follows its selected SDLC; other domains supply their
own workflow and checks.

| Method | Role |
| --- | --- |
| [Triage](agentic-triage/SKILL.md) | Investigate and disposition software ideas and issues |
| [Spec](agentic-spec/SKILL.md) | Specify a bounded software outcome |
| [Implement](agentic-implement/SKILL.md) | Produce and verify a software candidate |
| [Review](agentic-review/SKILL.md) | Independently assess the actual software candidate |
| [Security](agentic-security/SKILL.md) | Authorized, scoped defensive investigation and remediation evidence |
| [Evaluate](agentic-evaluate/SKILL.md) | Shared comparison across domains; commissioned by AgentOps |

Dedicated BI and research methods are not packaged yet. Use agreed task-specific
criteria without claiming those modules shipped. The project owns its purpose,
standards and delivery rules. Foundation prepares the selected setup; AgentOps
coordinates within the owner's mandate.
